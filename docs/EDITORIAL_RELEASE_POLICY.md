# Política de publicação editorial

Uma melhoria editorial pode ser publicada quando o owner já existe, a intenção é preservada, há ganho real de informação, a revisão técnica e de segurança passa, os links e schema permanecem íntegros e o build é aprovado.

O experimento histórico D0/D7/D14 é observacional. Seus snapshots e limitações continuam preservados, mas D14, GSC e Bing não são requisitos de autorização editorial. Quando indisponíveis, devem ser registrados como limitação de observabilidade.

Esta política não remove bloqueios reais: conteúdo inseguro, canonical inválido, schema quebrado, 404, regressão de sitemap, duplicação alta, claim sem prova, dados locais fictícios ou falha de build continuam impedindo publicação.
